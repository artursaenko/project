# 🎵 Звуки Животных - iOS Приложение

Простое и увлекательное iOS приложение, которое воспроизводит звуки различных животных при нажатии на их иконки.

## 🐾 Функциональность

Приложение включает в себя 5 животных с их характерными звуками:
- 🐱 **Кот** - мяуканье
- 🐶 **Собака** - лай
- 🐄 **Корова** - мычание
- 🦁 **Лев** - рычание
- 🐘 **Слон** - трубение

## 🛠 Технические характеристики

- **Язык программирования**: Swift 5.0
- **Платформа**: iOS 14.0+
- **Фреймворк**: UIKit
- **Аудио**: AVFoundation
- **Интерфейс**: Storyboard с Auto Layout

## 📱 Особенности интерфейса

- **Красивый дизайн**: Яркие кнопки с эмодзи животных
- **Анимации**: Плавные анимации при нажатии на кнопки
- **Адаптивность**: Auto Layout для поддержки разных размеров экранов
- **Тени и скругления**: Современный дизайн с тенями и скругленными углами

## 🎨 Цветовая схема

- Кот: Оранжевый (`systemOrange`)
- Собака: Коричневый (`systemBrown`)
- Корова: Розовый (`systemPink`)
- Лев: Желтый (`systemYellow`)
- Слон: Серый (`systemGray`)

## 🔧 Настройка проекта

### Требования
- Xcode 14.0 или новее
- iOS 14.0 или новее
- Swift 5.0

### Установка звуковых файлов

**ВАЖНО**: Для полноценной работы приложения необходимо добавить звуковые файлы в папку `AnimalSounds/Sounds/`:

1. `cat.mp3` - звук мяуканья кота
2. `dog.mp3` - звук лая собаки
3. `cow.mp3` - звук мычания коровы
4. `lion.mp3` - звук рычания льва
5. `elephant.mp3` - звук трубения слона

### Запуск проекта

1. Откройте `AnimalSounds.xcodeproj` в Xcode
2. Добавьте звуковые файлы в папку `Sounds` через Xcode
3. Выберите целевое устройство или симулятор
4. Нажмите ⌘R для запуска

## 🎯 Как добавить звуковые файлы

1. Найдите короткие (2-5 секунд) звуковые файлы животных в формате MP3
2. Переименуйте их согласно списку выше
3. В Xcode перетащите файлы в папку `Sounds` в навигаторе проекта
4. Убедитесь, что они добавлены в Target приложения
